## Bugs reproduced and fixed

- **Missing or incorrect local evidence.** Relative file references were tested
  against the process working directory before applying `--root`, losing valid
  logs. `file://other-host/path` could also read an unrelated local `/path`.
  Resolution now precedes the existence check, supports relative `file:` URIs,
  and rejects remote or malformed URI authorities.
- **Bundle finalization replaced Bazel's exit status with a crash.** An invalid
  deferred BuildToolLogs URI raised during finalization, preventing any report
  from reaching stdout. It now records `invalid_uri`, continues capturing valid
  references, finalizes a partial bundle, and preserves the process exit code.
- **Verification could hang, crash, or report false success.** A FIFO manifest
  blocked before regular-file checks, symlink loops raised an uncaught error,
  and an empty string/object in `artifacts` verified as an empty collection.
  The verifier opens manifests nonblocking, requires regular files and proper
  collection types, and reports path-resolution errors with exit code 2.

Six new regression tests failed against the prior implementation and pass with
the fixes. These changes retain the existing report and bundle schemas.

## Choices

Fix URI resolution at the shared reader rather than compensating in individual
test/action handlers, so all compact evidence uses the same rules. Record an
unavailable artifact rather than fail an invocation for optional archive input.
Validate the verifier's read boundary and collection shape without introducing
a schema-validation dependency or changing the manifest version. Preserve the
six existing commits and fast-forward main if its remote base remains unchanged.

Existing limits documented in the earlier validation and bundle notes still
apply, including bounded excerpts but unbounded total state, no remote CAS
fetching, no hermetic replay, and no authenticated bundle provenance.
